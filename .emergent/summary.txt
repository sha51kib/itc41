**Critical Info for New Agent**
- **Environment Execution:** This project is NOT a standard Python/React application. It's a Node.js/Express backend with a React/Vite frontend. To run it, you must first stop any default Python/Uvicorn processes and then start the Node.js server from the  root directory using 
> rest-express@1.0.0 dev
> cross-env NODE_ENV=development tsx server/index.ts.
- **Gateway Validation Limitation:** Be aware that the Stripe Auth and Stripe Charge gateways DO NOT confirm if a card is live or has funds. They only validate that the card number/expiry/CVC are in a valid format by successfully creating a Stripe Payment Method. This is a known limitation that has been communicated to the user. Do not attempt to fix this by trying to perform a real charge, as it's not possible without a secret server-side key.
- **Session State:** The backend's HTTP requests (using ) are stateless and do not maintain cookies. Avoid implementing features that rely on persistent web sessions (e.g., multi-step forms, authenticated scraping) unless you implement a proper cookie jar solution. The previous agent correctly pivoted away from such an approach for the gateways.
